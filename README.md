## 🚀 Objectiu del Projecte
L'objectiu d'aquest projecte és desplegar una aplicació web en PHP sobre una arquitectura de dos servidors independents (Servidor Web i Servidor de Base de Dades), corregir els bugs presents en el codi original (codeshare) i documentar tot el procés utilitzant Git i Markdown.

## 🏗️ Resum de l'Arquitectura Desplegada
- **Servidor Web:** NGINX + PHP
- **Servidor de Base de Dades:** MySQL
- **Repositori:** GitHub (públic)
